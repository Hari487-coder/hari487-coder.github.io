# hari487-coder.github.io

My life ledger: IITH coursework, assignments, and everything I ship, as one public
site at https://hari487-coder.github.io/. Built with Astro; content is markdown
managed through Claude Code + git.

## Run

```
npm install
npm run dev
```

## Test + build

```
npm test
npm run build
```

## Deploy

Push to `main`. GitHub Actions builds and deploys to Pages; a daily cron rebuild
keeps the date-driven dashboard honest. See `CLAUDE.md` for content conventions.
